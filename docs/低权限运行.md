# 可选的 Windows 普通账户运行

这是[独立运行目录](运行目录与访问保护.md)的高级选项。普通双击与 Node.js 运行不需要创建账户或计划任务。

## 配置原则

由部署者选择自己的独立运行目录、需要保护的目录与专用账户。默认服务账户名是通用产品名称 `XiangWaService`；账户须为新增普通账户，安装工具拒绝接管已有同名账户。

安装及权限恢复需要管理员权限。手动 S4U 任务不设置开机、登录或定时触发，日常启停使用目标运行目录的快捷方式。程序、二进制和普通配置只读；数据、日志与状态目录可写。Windows公共系统资源仍共享，这不等同虚拟机。

## 安装示例

先完成独立目录部署，再在管理员 PowerShell 中明确填写自己的目录：

```powershell
& 'C:/Games/XiangWa/setup-isolation.ps1' -Action Install -Root 'C:/Games/XiangWa' -ProtectedPaths $env:USERPROFILE
```

示例路径只是部署者可以选择的目录。不要把运行目录放到它要禁止访问的目录内。`ProtectedVolumeRoots` 是可选项，应由部署者按自己的磁盘安排指定；工具不会使用其他电脑的路径清单。

## 状态与恢复

```powershell
& 'C:/Games/XiangWa/setup-isolation.ps1' -Action Status -Root 'C:/Games/XiangWa'
& 'C:/Games/XiangWa/runtime.ps1' -Action Status -Root 'C:/Games/XiangWa'
& 'C:/Games/XiangWa/setup-isolation.ps1' -Action Restore -Root 'C:/Games/XiangWa'
```

恢复操作依据本机 `config/admin/isolation-backup.json`，先核对账户身份与任务归属。权限备份属于部署者的私有运维资料，不提交仓库或发送给其他部署者。
