# 标志种类与效果

更新：2026-10-26。依据用户提供的《标志的种类与效果》说明板照片，并已由用户确认使用这张图片作为标志资料。

这里的“角落标志”是此前交流中对放置在地图角落的标志的简称。说明板还包含钥匙、箱人等其他用途的标志；表中每一类图示不代表实物只有一枚，也不代表每类均在开局混入地图。

## 可以确定的数据

- 说明板列出14类标志。
- 手记为10种；密码的数字范围为1—6，保险箱需3个数字且顺序无关。
- 讨伐道具与讨伐情况各有白木棒、汽油、锈锁链三种对应内容。
- 两张说明板照片展示的是相同的种类与效果，本次补发照片文字更清晰。

“种类”和“实物数量”分开记录：说明板没有逐类列出实物数量或完整开局混合清单，不能从单个图示推断各一枚，也不能据地图24个角落倒推一套配置。后续优先从已有说明书的配件表和准备步骤补全；目前先使用已确认的种类与效果，不反复要求用户补拍同一份图示。

## 与卡牌的关联

- [访问者道具](访问者道具.md)中的归纳推理法可将空箱的X面朝上，箱娃或箱人潜入房间时可选择将其重新盖放。
- 夜视仪与手记公开、选择继承道具有关；行李箱可增加当前房间一个放置空箱标志的位置。
- “我在你身后”的实际卡面阶段与门槛见[箱娃之力](箱娃之力.md)，不要继续沿用此前仅据说明书笔记推定的即时触发时机。
