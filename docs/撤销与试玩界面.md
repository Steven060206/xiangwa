# 撤销与试玩界面

## 本轮实现

- 初始领取、主动道具、夜视仪领取均显示效果；已持道具可回看效果，旧存档采用当前已核对文案。
- 地图标明访问者的公开房间位置和座位编号；本人箱娃或箱人能看到自己的秘密角落，其他人看不到。
- 电脑地图与当前操作并排，手机上下分区，信息在各自区域滚动；提供专看地图，常用操作优先。
- 游戏成功操作记录最近40步，可逐步撤销到同一桌的历史状态。撤销是本项目的联机辅助功能，不冒称实体规则。

## 撤销约定

用户确认：只涉及自己的步骤不必让全体同意。本人最近一次未公开配置（准备、密码弱点、亡骸、初始潜伏、查看房间、秘密能力设置或回收）可直接撤回。公开选择、抽牌、窥探结算、移动、交换、死亡及结局等共同进度，需要发起时其他在线真人同意；人机自动同意。一个真人和三个人机时可直接执行。

撤销只退一步，再次操作可继续往前退。已经看到的秘密无法从玩家记忆中消除，联机玩家应在同意前确认接受退回。请求期间暂停游戏操作与人机；拒绝或取消保持当前盘面。撤销完成后人机先暂停，由房主点击“继续人机”，或下一次真人成功操作后继续，防止立即重做。

请求只包含一般步骤说明和同意者，不包含历史盘面、密码、手牌、凭证或秘密角落。盘面、牌序、角色、准备与日志同步回退；身份和连接保留，版本递增。历史与待同意请求随原存档保存，保存失败不生效。加入、离席、移除或补齐席位会清空撤销历史，不能用撤销复活已退出的身份。旧存档从本版本的新操作开始记录。

网页提交普通操作时附带所依据的进度版本。过期请求不改变盘面，避免网络延迟或多标签操作重做已经撤销的步骤；撤销投票按请求ID接受回应，在线状态变化不影响版本。投票期间切楼层、定位玩家或展开位置对照仍可查看地图，普通游戏控件持续禁用。

屏幕高度不足（例如手机横屏）时允许整页滚动，保证操作可到达；常规桌面和手机竖屏保留地图与操作分区。

## 验证与交付

开发及对应测试完成后统一运行 `npm test`、`npm run test:browser`、`npm run verify:references` 与 `git diff --check`，检查电脑及手机截图，再创建提交。保持4174原存档；仅后端更新需重启游戏进程，刷新后恢复原座位。
