# 道具与箱娃之力的联机结算

更新：2026-11-10。本页记录当前实现、原图依据和组合解释；卡面全文分别见[访问者道具](访问者道具.md)与[箱娃之力](箱娃之力.md)。本日用户新版裁定优先：每板一房，初始能力随机三抽一并保密，普通潜伏只查看被替换的一枚。

## 主动道具

[说明书第7页](../references/rules/rulebook-photo-08.jpg)将使用道具列为标准行动，并明确智能手机、笔仙、占卜棒等访问者道具可多次使用。只有写明单次使用的卡或标志在使用后消耗。

| 道具 | 联机操作与信息范围 |
| --- | --- |
| 笔仙 | 同房必须有另一名存活访问者，指定房间提问；箱娃回答是／否，答案公开。 |
| 腹语人偶 | 指定房间，公开实际场上手记并自动补备用空箱；箱娃确认是否叫喊“我是玛丽小姐”。不向访问者发送其余房间内容。 |
| 噩梦的来信 | 将牌库中的绝望时刻移至底部，不公开其余牌序，不弃置此访问者道具。 |
| 智能手机 | 选择一个已设置能力栏或一张手牌的序号，只将所选卡面发送给使用者。 |
| 占卜棒 | 箱娃选择回答所在楼层，答案公开。 |
| 深菱神社之铃 | 首次翻牌前选择额外翻一枚，完整翻完后还须声明并确认标准行动“使用铃”；接下来的首个箱娃阶段禁止新设置B／C能力，已有B／C仍可发动或回收。 |
| 行李箱 | 消耗标准行动，仅用一次；卡置于地图板下，从备用空箱取一枚，在当前房间新增“行李箱中”角落。该角落可窥探、讨伐、丢弃物品和潜伏。 |
| 古怪护符 | 消耗标准行动，移除一个已设置能力及护符。若移除生效中的鬼来电，其限制同时结束。 |

这些标准行动都先声明，待箱娃确认或打断后结算。本道具的再次使用仍需下一次标准行动。

### 同房致死与组合解释

笔仙、腹语人偶、来信、手机和占卜棒与箱娃同房时会致死。箱人同房不触发这些携带死亡条件。

- 手机卡面明确“不触发效果”；对讲机明确“查看前死亡”。其他主动卡没有单列效果与死亡的先后，本实现统一先处理同房死亡，再决定是否触发效果。
- 腹语扫描不包含已被箱娃／箱人藏匿、暂存在方位栏的底层标志；这是结合[第12页的暂存](../references/rules/rulebook-photo-13.jpg)与[第13页的不可获取](../references/rules/rulebook-photo-14.jpg)作出的组合解释，卡面没有另列穿透暂存物的规则。
- 腹语移走手记后按照[第6页补位通则](../references/rules/rulebook-photo-07.jpg)自动使用备用空箱；备用耗尽则留空，不强迫远程弃置使用者的随身标志。不是窥探，不触发夜视仪或归纳推理法。
- 行李箱卡面未另印标准／自由行动，采用第7页“使用道具”的标准行动通则。

## 哭喊与能力栏

依据[说明书第11页](../references/rules/rulebook-photo-12.jpg)：每个箱娃阶段按“可选哭喊 → 设置或回收 → 开始箱娃行动 → 阶段能力 → 潜伏”推进。

1. 每阶段最多哭喊一次，且在设置／回收前进行；公开当前宣告房间，私看牌库顶牌。地图标记保留到下一箱娃阶段开始；NO.11假哭只标宣告房间，不公布真假。
2. 对应编号手记已公开才取得该牌，否则放牌库底。按第二轮试玩反馈，NO.11开局固有，不进入抽牌库；累计第10次实际哭喊时保证取出绝望时刻并处理其效果，不能以第10回合代替。
3. 绝望时刻重新放底，再取顶上的两张可取能力；这两张与开局牌一样绕过手记门槛，不绕过时机、每局一次等限制。不足两张时取实际剩余能力，不复制卡牌或递归抽绝望时刻。
4. 两个能力栏各一张，盖放设置；每阶段最多设置一张，设置与回收二选一。本实现每次回收一张。
5. 设置时可尚未满足手记门槛；发动时另行验证。没有卡面特例时，发动后返回手牌。
6. 手牌、抽到并放回的牌和盖放能力只给箱娃。按2026-11-10试玩裁定，NO.1—4静默发动，能力栏立即变空；NO.5—10只宣告“箱娃发动了能力”。NO.9已设置时，每次合法回答均匿名宣告，回答真假仅箱娃知晓。持续占栏的能力对其他玩家保持盖放，必要操作提示不标注来源技能。普通潜伏不返回整房棋子，NO.4查看和重排细节继续保密。

NO.4发动时即回手，其查看内容和未完成的重排独立保存。完成重排只提交排列结果，卡牌只回手一次。刷新、重启和撤销均保留一致的能力栏、手牌及待重排状态。箱人看到的技能公开范围与其他访问者相同，阵营位置互见不增加技能卡面权限。手机私看、公开手记说明与正常终局复盘仍按各自规则显示。

匿名宣告以独立序号记录，同一周期的多次发动均可识别。同步重复送达不重复通知，刷新及重连以当前进度建立基线。NO.1—4不增加公开宣告序号，撤销说明使用“箱娃操作”，不重新公告技能。旧客户端的主动公开参数及旧存档翻面标记不改变这些范围。

## 已接入的能力

| 编号 | 效果与限制 |
| --- | --- |
| 1 | 本次箱娃可潜伏至同楼层任意房间，箱人仍按普通范围。 |
| 2 | 必须先发动再选路径，最多经过两间房，也可留在原房或只移一间；路径选择不查看途中棋子。 |
| 3 | 封锁一扇实际相连的门，不包括楼梯；下次箱娃阶段解除，下个阶段不能再次发动。箱娃和箱人可穿过。 |
| 4 | 查看一个房间，重排实际场上角落内容，可重新盖放；不移动演员或其暂存原物，不增删标志。 |
| 5 | 公开6片后可发动，效果延迟至下一次箱娃阶段开始前，按届时位置杀死箱娃同房全部访问者；届时公开8片额外包括箱人同房访问者。开局／绝望豁免只放宽发动门槛，额外箱人效果仍需8片。 |
| 6 | 打断已经声明的访问者行动，原行动取消；由该访问者自己选本房有标志的角落强制窥探。依据[说明书第15页](../references/rules/rulebook-photo-16.jpg)括号明文。 |
| 7 | 打断标准或自由行动，目标固定为当前声明者。指定抢一张访问者道具或随机一枚随身标志，先抢新物，再将上次赃物归还本次被抢者；原声明取消，可重新声明，不消耗标准行动或改变无声轮次。 |
| 8 | 打断后附着人偶持有者，从以后的翻牌回合起连续逐枚翻两枚。当前已开始的行动不追补；人偶不能转交、丢弃或补位。死亡或人偶被NO.7抢走时，诅咒解除且NO.8回箱娃手牌。 |
| 9 | 设置后持续允许对道具问题选择假答案；服务器验证回答是否合法，不自动替玩家选谎言。不能伪造手机卡面或手记。 |
| 10 | 每局一次，取消本次原声明，访问者只能沿最短可行路线向客厅移动。**用户已选择说明书版本：第一名访问者进入客厅后，全体解除**。生效期间留在能力栏，解除后回手但不能再发动。 |
| 11 | 已设置时哭喊可指向其他房间；假哭后的本次开始行动时回手，本局不能再次设置。公开宣告不带真假字段。 |

阶段能力在箱娃选择最终潜伏房间前完成。箱人等箱娃结束阶段能力、开始潜伏后再移动，避免并发操作使NO.5误用移动后的箱人位置。普通潜伏确认前不查看秘密内容，确认后仅保留被替换一枚的私有历史记录；NO.4仍按能力查看整板。箱人没有独立能力手牌或其他阶段能力。

**NO.5版本差异：**[旧图03](../references/cards/hako-powers-03.jpg)写箱娃行动阶段使用，[新图05](../references/cards/hako-powers-05.jpg)写倒塌瞬间发动。当前保持用户此前确定的箱娃行动阶段版本，保留6／8片门槛及延迟结算。灭火器按下方试玩裁定处理。

**封门与鬼来电组合：** 用户进一步确认，完全没有通往客厅路线时仍照常翻无声标志；若翻牌后本可行动，自动结束这次无路可走的行动，等待下一箱娃阶段封门解除。数字超过10仍按原规则触发阶段。这不是玩家主动持牌跳过，不消耗额外数字，也不取消鬼来电本身。

## 连续翻牌、铃与抢夺

### 无声模式连续翻牌

依据说明书的“堆叠一枚→翻开一枚”替换通则、[铃卡](../references/cards/visitor-items-02.jpg)、[NO.8新旧卡面](箱娃之力.md)及[作者官网FAQ](https://ejingar.sakura.ne.jp/hako/hako11.htm)组合结算；不是把实体堆叠卡面改称数字模式逐字规则。

1. NO.8附着后，人偶持有者以后的翻牌回合要求两枚；铃在首次翻牌前可选择额外一枚，单独用铃两枚，铃与NO.8合计三枚。
2. 每次点击只翻一枚，逐枚累计与判断。连续计划开始后不能改成持牌跳过或改变摇铃计划，未完成前不能声明标准或自由行动。
3. 数字合计大于10立即停止并进入箱娃阶段，不能继续翻剩余计划；重置后由触发者重新按当前要求开始，不保留上一轮欠牌。恰好10仍可继续完成要求并行动。
4. 最后一枚盖牌保留，不因多枚要求翻掉。NO.8按“场上剩余足够”的卡面限制，在牌数较少时以实际可翻数结算；铃是可选承诺，须有足够牌完成全部计划并留下最后一枚，否则不能选择。
5. 额外翻牌全部成功后，铃只获得本次标准行动的使用资格；还需声明“使用铃”并经确认才生效。改做其他行动不会发动铃，也不弃置铃卡。
6. 铃只影响接下来的首个箱娃阶段的**设置**：禁止B类NO.3、7、8及C类NO.4、9、10；A类NO.1、2、5、6与无等级NO.11仍可设。既有B／C可发动或回收；手记豁免不绕过铃的设置限制。危险度依据为[新三张合照](箱娃之力.md)。

持有者死亡弃置人偶或人偶被NO.7抢走后，NO.8回箱娃手牌，后续人偶交还不自动再次附咒。诅咒期间，人偶禁止普通给予、交换、丢弃与角落补位，能力强制抢夺按FAQ例外处理。若附咒使待确认的人偶转交、丢弃、交换或手机查看NO.8原能力栏失效，取消该声明，保留当前轮次供访问者重新声明，不追补本回合翻牌。连续翻牌计划、进度、附着卡和铃的已选／待确认状态均随存档恢复。

### NO.7的目标与秘密信息

[新卡面](../references/cards/hako-powers-05.jpg)指定“当前访问者”，说明书允许打断标准与自由行动且没有同房要求。服务器将目标固定为待确认行动的 `pending.playerId`；自由行动也不能另抢无声轮转中的其他玩家。

- 访问者道具可指定一张；随身标志只能随机取一枚，箱娃界面只知是否有可抢标志，不得到秘密标志列表或ID。没有对应物品时不能抢，旧赃物不参与新一轮选择。
- 箱娃可查看赃物，其他玩家不能从HTTP、SSE、轮询或公共日志得到赃物内容。再次发动时，旧赃物交给本次被抢者，而不是自动找回最初持有者。
- 抢夺取消原声明但不消耗标准行动、不推进无声轮次，被抢者可重新声明。错误请求或保存失败不改变库存、赃物、阶段或版本；赃物及待确认窗口随存档恢复。

## 灭火器与群体死亡

[说明书第14页](../references/rules/rulebook-photo-15.jpg)记载实体版的杂音倒塌及NO.5发动响应。以下采用2026-11-10用户确认的联机版时机。

- 无声模式翻牌使累计超过10时，仅本次翻牌者存活且持有灭火器才出现使用／放弃选项。其他持有者不能响应。
- 累计恰好10或仅剩一枚盖牌时均不开放窗口。进入箱娃阶段后不能使用，包括NO.5发动时。
- NO.5发动后直接登记延迟效果，待结算提醒仅箱娃可见。
- 使用后消耗灭火器，跳过本次箱娃及箱人行动。到期的NO.5仍在阶段边界结算；有遗物继承时，处理完后存活访问者才能继续行动。
- 放弃响应不消耗灭火器，也不允许他人接替。群体死亡先处理全部受害者，再依次让所有仍有存活接收者的死亡玩家选择继承。不能把遗物交给同次能力已经杀死的人。

灭火器的使用者若被到期NO.5杀死，下一轮转交其后的存活访问者。全员死亡直接进入结局。人机使用同样的过滤视图和响应资格。

旧存档中的NO.5灭火器窗口恢复时关闭，保留已登记的延迟效果和已发动状态，不扣除灭火器或恢复取消发动的副本。旧超限窗口仅保留本次翻牌者的合法资格，已放弃的窗口不重新开放。兼容处理也适用于撤销恢复，读取玩家视图不结算死亡或改写存档。

## 网络动作

| 动作 | 主要参数 |
| --- | --- |
| `use_item` | `itemId`，依道具提供 `roomId`、`targetZone`／`index` 或护符 `tokenId`。 |
| `silent_reveal` | `index`；首次翻牌可提供布尔值 `useBell`，连续计划开始后不可改变。 |
| `answer_item` | 箱娃提供 `answer`：布尔值或楼层数字。 |
| `hako_cry` | 可选 `roomId`；没有NO.11时只能真实房间。 |
| `set_power`／`recall_power` | 手牌 `powerId` 与能力栏 `slot`，或仅 `slot`。 |
| `begin_hako_action` | 结束准备，进入能力与潜伏。 |
| `activate_power` | `slot`，旧客户端的 `public` 参数不影响公开范围；依能力提供目标房间或两端房间；NO.7提供 `stealKind: 'item'`及`itemId`，或`stealKind: 'token'`随机抢标志，拒绝指定`tokenId`。 |
| `power_rearrange` | 所选房间内容源角落的全排列 `order`、可选重新盖放列表。 |
| `inspect_path_room` | 沿用旧接口名，NO.2选择实际经过房间 `roomId`，不返回棋子内容。 |
| `publish_token` | 访问者提供本人持有或当前窥探发现的 `tokenId`；无标准行动消耗，产生全局历史公开记录。 |
| `choose_forced_peek` | 被NO.6打断者选择 `cornerId`，可先选择是否用夜视仪。 |
| `extinguisher_response` | 本次翻牌超限且持有灭火器的访问者提供布尔值 `use`。 |

动作保持副本事务语义；错误请求不改变盘面或版本。箱娃隐藏行动期间，访问者看到的角落占用与正面标志保持开始行动时的公开快照，直到重新睁眼。

## 模式与当前边界

- 对讲机远程互看要求双方均持有；本局候选池每种一张，没有两个持有者，不复制卡牌来制造该效果。同房普通展示照常可用。
- NO.12按卡面要求不进入无声模式。
- 已支持本地自动存档、重启恢复与Windows电脑临时公网分享，使用方法见[README](../README.md)及[电脑公网联机](异地联机.md)。
