# 箱娃：四人联机版规则笔记

更新：2026-10-25。依据用户提供的说明书第1—15页照片；第1页有两张照片。

本文记录已读出的规则和已确认的选择，是开发前的规则笔记。九块地图和两块辅助板已补充实物照片；卡牌与角落标志数据仍待补充。

## 已确认的产品选择

- 四名真人玩家：一名箱娃、三名访问者。
- 用户已选择说明书的官方“无声模式”，用数字标志代替实体杂音堆叠。
- 浏览器网页、房间码加入，是此前提出的首版方案；尚未实现。
- 首版应保留逃脱、讨伐、超度三条胜利路线，以及死亡后变成箱人的规则。

## 地图准备阶段（第3页步骤②）

先取出1楼大厅，再洗混其余八块板。从箱娃左手边的访问者开始，访问者轮流抽一块板并自行选择摆放位置和方向；至少有一扇门与已摆放的房间门对门相接。抽到2楼大厅或地下室时分开放置；2楼大厅放置后，之后抽到的板可以选择接到二楼。九块全部拼完后，访问者指示物放到正门，再继续后续设置。

联机版应让访问者完成抽板、旋转和确认摆放，并校验连接条件。详见[地图资料中的准备阶段](地图资料.md)。

## 阵营与胜负（第7—10页）

访问者阵营只要有人达成以下任一条件，即取得胜利：

| 路线 | 需要完成的事情 |
| --- | --- |
| 逃脱 | 推断保险箱的三个密码数字；窥探保险箱并输入正确数字取得钥匙；携带钥匙窥探隐藏出口。密码数字范围为1—6，顺序不计。 |
| 讨伐 | 获取汽油、白木棒、锈锁链之一；对箱娃实际潜伏的角落使用与其弱点匹配的道具。讨伐情报标志指出无效道具，两个情报可推断弱点。 |
| 超度 | 携带“玛丽小姐的人偶”，窥探亡骸所在角落。 |

箱娃的目标是阻止三条路线并消灭访问者。所有访问者死亡、所有路线均已无法达成，或访问者投降时，箱娃获胜。

访问者死亡后道具公开并移出游戏，玩家转为箱人，与箱娃共同阻碍访问者。箱人的藏身仍然保密，不按普通访问者公开位置；其可用能力、被讨伐方式与箱娃存在区别。

## 无声模式的回合流程（第2—3页）

1. 将六枚无声标志洗混、背面朝上排成3×2；数字为0—5。
2. 访问者按座次依次行动。每人行动前选择翻开一枚无声标志。
3. 正面朝上数字合计小于或等于10时，该访问者正常进行自己的行动；恰好10仍可行动。
4. 合计大于10时，该访问者不执行行动，直接进入箱娃阶段。
5. 箱娃阶段结束后，重新洗混并盖放无声标志，从本次未能行动的访问者继续。
6. 可以选择不翻牌并跳过本回合，取一枚仍盖着的无声标志暂放手边。箱娃阶段后重新配置时才归还。数字0已经正面朝上时不能选择跳过。
7. 桌面只剩一枚盖放的无声标志时，当前回合结束后也进入箱娃阶段；重置后由上次完成翻牌并行动的访问者的下一位继续。
8. 说明书要求将卡牌中的“堆叠指示物”替换为“翻开一张无声标志”，将“指示物倒塌”替换为“数字合计超过10”。涉及一次要求多枚指示物的卡牌，需结合卡面核对换算。

### 访问者行动（第5—7页）

- 每回合选择一个标准行动：移动、窥探角落、使用道具。
- 自由行动包括与同房访问者展示或交换标志、在空角落丢弃标志、口头交流等，按规则可多次进行。
- 移动需要相邻房间双方的门相连；可走规定的楼梯连接。访问者不能穿过封锁的门。
- 窥探只限自己房间内的角落。窥探者独自查看内容，按标志种类决定获取、盖回或处理效果。
- 取走标志后通常用空箱标志或弃置的随身标志补位；没有可用补位物且不愿弃物时，角落可以留空。空角落不能窥探。
- 手记标志一经发现立即公开，并放在对应编号的手记牌上；公开手记会解锁箱娃之力。
- 某些道具若在箱娃潜伏的房间使用，会立即杀死使用者；不能把“同一房间”和“同一角落”混为一谈。

### 箱娃阶段（第10—12页）

顺序为：哭喊（可选）→设置或回收能力（可选）→访问者闭眼→发动阶段能力（可选）→移动及潜伏（可选）→访问者睁眼。

- 哭喊时公开所在房间，并按规则尝试取得能力牌；并非每次哭喊都能获得能力。
- 左右两个可用能力栏各可设置一张能力牌；多数能力使用后返回手牌。
- 通常最多移动至相邻房间，也可以不移动或在同房换角落；特殊能力可能改变移动范围。
- 箱娃先选目标房间，查看该房间所有角落标志，再选择潜伏角落；原本的角落标志由箱娃保管，离开时归还。
- 部分能力能在访问者声明行动后、效果实际完成前打断；联机交互必须留出这个时机。
- 无声标志累计超过10时，箱娃可能有即时反应能力，不能直接跳过反应结算。

## 联机实现需要保留的信息边界

- 服务器保存完整盘面并判定行动是否合法、是否触发死亡与胜负。
- 公共信息包括访问者位置、公开手记、无声数字、阶段与行动顺序。
- 隐藏角落内容、随身标志、能力手牌及箱娃、箱人的潜伏位置，只按规则发送给有权查看的玩家。
- 公共日志不能泄露秘密窥探内容、箱娃选定的角落或未公开的弱点和密码。
- 同房展示和交换应由玩家主动执行；口头交流可由玩家自行进行。
- 箱娃阶段的“闭眼”应通过服务器限制客户端可见信息实现。
