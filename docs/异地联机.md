# 自行部署与异地联机

完整的安装、邀请码、局域网与临时分享步骤见[自行部署](自行部署.md)。每个部署者在自己的电脑运行服务，使用自己的存档与访问记录。

## 临时分享

先运行 `npm start`，另开终端运行 `npm run share`。Windows 也可双击“启动游戏.cmd”和“远程联机.cmd”。临时分享不要求域名或 Cloudflare 账户；macOS／Linux 需先安装 cloudflared。

请从分享窗口显示的同一个 HTTPS 地址进入游戏，再验证邀请码、建房和分享房间。两个窗口都需要持续运行；临时网址变化时，浏览器身份不会自动迁移到新网址。

## 可选：自己的固定域名

需要稳定网址时，由部署者按 [Cloudflare 官方说明](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/) 创建自己的命名隧道和域名记录。

`npm run share:fixed` 读取本机 `%LOCALAPPDATA%/XiangWa/fixed-entry.json`，其中仅需部署者自己的信息：

```json
{
  "hostname": "game.example.com",
  "tunnelId": "00000000-0000-0000-0000-000000000000",
  "credentialsFile": "C:/private/tunnel.json"
}
```

以上为不可用的示例，须自行填写。该文件与凭证只保存在部署者本机，不提交到仓库或放入分发包。启动服务后，在 Windows PowerShell 运行 `npm run share:fixed`；端口可用 `-- -Port 4173` 指定。

分享脚本检查本机健康接口，仅代理指定主机名，其他主机名返回404。它不会代替部署者创建账户、DNS记录或隧道。
