## 已读到的编号能力

### NO.1 就在你身旁

来源：[箱娃之力02](../references/cards/hako-powers-02.jpg)。

- **时机：箱娃行动阶段使用。**
- 本次移动可以移动至本层任意一个角落。
- 已公开5片及以上手记标志后，才可以使用该能力。
- 不满足条件时，可以先设置在可用能力栏。

### NO.2 马上就到哟

来源：[箱娃之力02](../references/cards/hako-powers-02.jpg)。

- **时机：箱娃行动阶段使用。**
- 本次移动时，箱娃可以额外移动1个房间；也可以如常移动1个房间，甚至完全不移动。
- 已公开3片及以上手记标志后，才可以使用该能力。
- 不满足条件时，可以先设置在可用能力栏。
- 卡面没有另写“查看经过房间所有角落”的效果；经过房间的查看规则需按说明书相应条款处理，不能仅由这张卡推导。

### NO.3 打不开的门

来源：[箱娃之力01](../references/cards/hako-powers-01.jpg)。

- **时机：箱娃行动阶段使用。**
- 在任意一扇门上放置1个封锁指示物。
- 封锁指示物直到下一次箱娃阶段才会解除；封锁期间，访问者无法通过这扇门。
- 使用一次该能力后，下一次箱娃阶段无法使用。
- 卡面没有列出公开手记门槛，也没有在本段单独叙述箱娃、箱人的穿门规则。

### NO.4 动来动去

来源：[箱娃之力01](../references/cards/hako-powers-01.jpg)。

- **时机：箱娃行动阶段使用。**
- 查看任意一个房间（红色框围起来的区域）内所有角落标志，并任意替换位置。
- 此时可以将标志从正面翻回背面。
- 游戏开始时，箱娃玩家无法选择该能力作为初期能力。
- 卡面没有列出公开手记门槛。

### NO.5 我在你身后

来源：[箱娃之力03](../references/cards/hako-powers-03.jpg)。

- **时机：箱娃行动阶段使用。**
- 与箱娃处于同一房间的所有访问者死亡。
- 已公开6片及以上手记标志后，才可以使用该能力。
- 不满足条件时，可以先设置在可用能力栏。
- 如果已公开8片及以上手记标志，与箱人处于同一房间的访问者也会死亡。
- 卡面没有把“指示物倒塌”或“无声数字合计大于10”写作该能力的直接发动时机，也没有在本段写出“公开潜伏位置”的步骤。

### NO.6 好想打开它

来源：[箱娃之力01](../references/cards/hako-powers-01.jpg)。

- **时机：打断访问者行动发动。**
- 被指定的访问者的行动改为强制窥探其所在房间的任意一个角落；正面朝上放置的角落标志也能选择。
- 已公开5片及以上手记标志后，才可以使用该能力。
- 不满足条件时，可以先设置在可用能力栏。
- 卡面没有进一步说明由谁选择具体角落；不能仅根据本张卡额外指定选择者。

### NO.8 我的玛丽小姐

来源：[箱娃之力03](../references/cards/hako-powers-03.jpg)。

- **时机：打断访问者行动发动。**
- 将本卡交给携带玛丽小姐的访问者。
- 此后，玛丽小姐无法被交换或丢弃。
- 携带玛丽小姐的访问者在行动前必须堆叠2片指示物。
- 没有人携带玛丽小姐时，使用该卡没有任何效果，返回手牌。
- 卡面没有列出公开手记门槛，也没有写出持有者死亡等情况的后续处理。
- 卡面保留的是实体堆叠规则；无声模式下“2片”的换算及中途触发箱娃阶段后的剩余处理，仍不能仅凭此卡确定。

### NO.9 虚假的回应

来源：[箱娃之力03](../references/cards/hako-powers-03.jpg)。

- **时机：设置在可用能力栏后。**
- 回答访问者道具触发的提问时，可以说谎。
- 卡面没有列出公开手记门槛、次数或主动回手条件，也没有限定只对应某几张点名道具。

### NO.10 鬼来电

来源：[箱娃之力02](../references/cards/hako-powers-02.jpg)。

- **时机：打断访问者行动发动。**
- 所有访问者在到达客厅前，只能选择沿最短路径移动至客厅的行动。
- 该能力在一场游戏中只能使用1次。
- 效果发动中，该卡牌一直放置在可用能力栏。
- 卡面末句为：“这能力发动时可以使用其它能力打断访问者行动”。
- 卡面没有列出公开手记门槛；“所有访问者在到达客厅前”的表述没有明说首位访问者到达时全体解除，不能直接补成“有人到达即结束”。

### NO.11 虚假的哭喊

来源：[箱娃之力02](../references/cards/hako-powers-02.jpg)。

- 卡面标注：**无额外条件直接获得的能力。**
- 在可用能力栏设置此卡后，可以在声明“哭喊”时，用手指指向“箱娃”标志所不在的房间。
- 一旦这样做，在本次箱娃行动、访问者闭眼期间，将该卡从可用能力栏拿回手牌。
- 该能力在本场游戏中无法再次设置在可用能力栏。

### NO.12 天旋地转

来源：[箱娃之力03](../references/cards/hako-powers-03.jpg)。

- 卡面标注：**无额外条件直接获得的能力。**
- **时机：在可用能力栏设置此卡后，访问者堆叠红色指示物时发动。**
- 该访问者必须将红色指示物反过来，以突起物在下方的状态堆叠。
- 该能力一旦使用，就从游戏中移除。
- 卡面明确写明：**“无声模式时，将该能力从游戏中移除”。** 本项目采用无声模式，因此此能力不进入可用能力流程，无需推定红色指示物的数字换算。

## 解放卡：绝望时刻

来源：[箱娃之力01](../references/cards/hako-powers-01.jpg)。卡面标题为“箱娃之力 解放”，没有NO.编号。

1. 箱娃玩家抽到此卡后，将此卡重新放置在牌库最下层。
2. 随后立即从牌库上方拿取2张牌加入手牌。
3. 通过此手段获得的卡牌，和游戏开始时选择的1张卡牌一样，即使不满足手记标志已经公开的条件，也可以使用。

卡面明确的是绕过**公开手记条件**；没有写成解除所有使用时机、次数、模式排除或其他限制。此前说明书第15页正文与括号对手记门槛的表述不一致，现在可按本卡明确文字修正该处记录。

## 对此前规则索引的校正

| 此前记录 | 本批卡面支持的结论 |
| --- | --- |
| NO.5作为倒塌或无声合计大于10时的即时反应能力，并公开位置 | 卡面明确为“箱娃行动阶段使用”。6片与8片是公开手记门槛，不能把大于10这一阶段触发条件当作此卡直接发动窗口；公开位置步骤也不见于本卡。 |
| NO.5“箱娃至少6片；箱人至少8片”的简写 | 卡面写的是6片后可使用、同房箱娃致死；8片后，同房箱人也致死。应保留这两个效果层次，不能将同房箱人的效果独立改造成另一个未经核对的发动流程。 |
| 能力索引只有1—10 | 实物本批还包含NO.11“虚假的哭喊”和NO.12“天旋地转”。本批未拍到NO.7，现有照片不能支撑宣称已核齐全套。 |
| NO.2索引含“查看经过房间的角落” | 本卡明确额外移动1间；经过房间的查看需要说明书另行支持，不能作为卡面逐字内容。 |
| NO.10“直到有人进入客厅” | 本卡写“所有访问者在到达客厅前”，没有明确首次到达就全体解除；该解除范围仍需结合说明书核对。 |
| “绝望时刻”获得的能力是否仍受手记门槛限制待定 | 卡面明确新得的2张牌和开局选择的1张牌均可绕过公开手记条件。 |
| 所有能力都需要换算无声模式的实体指示物效果 | NO.12明文要求在无声模式中移除；NO.8的2片堆叠仍需核对具体换算，不能自行造出数字效果。 |

NO.1、NO.2、NO.5、NO.6都明确允许在公开手记条件未满足时先设置到可用能力栏；**设置合法**与**当前可发动**必须分开判定。NO.4初期禁止、NO.11本局禁止再次设置、NO.10每局一次、NO.12无声模式移除，也应分别保留，不能统一为“使用后回手即可再次设置”。
