## 按说明书执行的准备顺序

### ① 访问者指示物及道具

2026-10-31新增五人模式：建房时固定为一箱娃、四访问者；四人模式仍为一箱娃、三访问者。下文历史“三名访问者”在五人模式中对应四名，所有访问者均须领取不同道具，再轮流摆放八块待抽地图；初始标志池、九块地图及六枚无声标志不因人数增加而变化。

- 访问者选择颜色，取得同色箱人标志；四人对局只使用三名访问者对应的指示物和箱人标志。
- 从箱娃左手边的玩家开始，每位访问者依次选择并取得一张访问者道具。
- 本说明书写的是“从6个访问者道具中”选择；当前补充实卡确认12种道具。用户已于2026-10-26明确选择：**12种全部进入候选池，三名访问者各选1张**。这是本项目采用的配置，不将照片前六张当作官方六张；夜视仪的未选池也应对应本局采用的12种候选。

### ② 拼接地图

按照[地图资料](地图资料.md)的既有抽板和门对门规则完成九块地图；访问者先位于正门。

### ③ 留出空箱备用

找出24片空箱标志，全部放在地图之外备用。初始配置不把空箱混入地图。

### ④ 密码

找出1—6的六片密码标志，任选三片盖放在保险箱板的三个密码槽；其余三片进入稍后的地图混合池。密码由三个不同数字组成、顺序无关，不能允许重复数字。

说明书使用“任选”，未指派由哪位玩家主动挑选数字。当前联机实现由箱娃在私有表单中选择三片，服务器保管，不向访问者发送；不是写死或允许重复的密码。第7页明确箱娃可以查看保险箱板上的标志以核对密码。

### ⑤ 弱点

找出三片讨伐情况标志，任选一片盖放到箱娃板的“弱点”栏，其余两片进入地图混合池。

弱点栏使用的是带红叉的情报标志，但在此处以其对应道具身份代表箱娃的有效弱点。第8页及第14页明确：命中箱娃后，对比所用讨伐道具和弱点栏，身份相同即成功讨伐；在地图中发现的其余两片才表示对应道具无效。不能把弱点栏中道具也处理成免疫。

弱点在公开命中结果前保持盖放，访问者不能从视图或日志获知其内容。

### ⑥—⑧ 固定与保留标志

- 先取出保险箱、钥匙、亡骸、箱娃四种标志。
- 保险箱正面放到书房“写字台下”，开局时转为盖放；初始不能随机分配保险箱位置。
- 钥匙放到保险箱板下方钥匙栏。
- 箱娃、箱人、亡骸不进入随机池；箱人随访问者留待死亡转化时使用。

### ⑨ 随机配置角落

把上述步骤后尚未使用、且不属于空箱／箱娃／箱人／亡骸的所有角落标志，加上剩余的三片密码、两片讨伐情况，彻底洗混后随机盖放到地图角落。保险箱已占一角；说明书明确随机配置完成后恰好留一个角落为空。

| 本局随机混合池 | 枚数 |
| --- | ---: |
| 手记1—10 | 10，各编号一枚 |
| 剩余密码数字 | 3，来自1—6中未放入保险箱的数字 |
| 剩余讨伐情况 | 2，对应非弱点的两种道具 |
| 白木椿、汽油、锈锁链 | 3，各一枚 |
| 玛丽小姐的人偶 | 1 |
| 隐藏出口 | 1 |
| 古怪护符 | 1 |
| 灭火器 | 1 |
| 合计 | 22 |

数量依据不是说明板每类只画一次：准备步骤⑨要求把所有尚未使用的适用标志全部混入，并明确最后只剩一个空角。结合已确认的10种手记、三种讨伐道具、四个其他适用类别及三片剩余密码、两片剩余情报，各类别至少一片的下限恰好是22，因而该开局池只有上表这一种数量分配。此表记录本局初始混合池，不代替整盒实物配件数量表。

### ⑩⑪ 箱娃秘密放置亡骸

从此步骤开始，访问者不再查看箱娃配置过程。

箱娃指定任意一个非保险箱角落盖放亡骸；建议远离访问者且不容易发现，但这是策略建议。如果目标角落原有标志，将其移到⑨留下的唯一空角；也可以直接把亡骸放在该空角。不能随意丢弃被替换的标志，也不能覆盖保险箱。

### ⑫⑬ 箱娃秘密初始潜伏

按用户2026-10-27新版裁定，箱娃选择儿童房板或书房／深色房间板，再选该板任意角落初始潜伏。选择前不查看秘密棋子；确认后只得知被替换的一枚，其他棋子仍保密。

旧版[说明书第4页⑫](../references/rules/rulebook-photo-05.jpg)与[第12页⑤](../references/rules/rulebook-photo-13.jpg)写有先确认房间所有标志；这条旧版流程保留为原图依据，当前网页改用上述用户新版选择。NO.4“动来动去”的整房查看是独立能力，不由普通潜伏自动获得。

确认潜伏后，网页保留最近一次被替换棋子的私有记录，可在选初始能力、探索及之后阶段回看，并随刷新和存档恢复。记录只含所选一枚，后续变化不自动更新；下一次确认潜伏后才替换。旧版保存的整房记录也只返回对应被替换的一枚；缺失时仅能从已保存的开局数据恢复初始被替换物，不读取当前秘密盘面补历史。

将箱娃标志盖放到所选角落，把该处原标志盖放在箱娃板的“方位”栏。该标志离开地图但仍保留，箱娃移动离开时归还原位；访问者看不到其内容和潜伏角落。完成后访问者恢复查看公开盘面。

### ⑭⑮ 手记与初始能力

- 公开按编号1—10排列十张手记卡。
- 用户2026-10-27第二轮试玩明确改为：NO.11“虚假的哭喊”为固有初始能力，无需抽取；另从NO.1—10随机抽三张不同的能力，箱娃秘密三选一，包括NO.4“动来动去”；NO.12仍按无声模式排除。候选随存档保存，刷新和重启不重抽。
- 候选和已选初始能力只对箱娃本人可见；访问者不取得编号、名称或解放标记。该初始手牌仍豁免公开手记数量门槛。
- 未选的两张与其余编号能力一同洗回普通牌库；牌库包含NO.1—10中未选的九张及“绝望时刻”，不含NO.11。旧说明书的1—10直接选择、初始公开标记及NO.4禁选是旧版资料，不再作为当前开局限制。
- “绝望时刻”有抽到后放回牌库底并再抽两张的明确规则，应保留在牌库处理；第5页的上述洗牌文字没有单独再次点名它。其获得的两张和初始牌一样绕过公开手记门槛，具体卡面优先于第15页括号内的旧文字冲突。
- 牌库顺序、初始牌及后续手牌均保密。

### ⑯ 入场

将全体访问者从正门移到一楼大厅。正门关闭，不作为隐藏出口。先配置无声模式0—5六片数字，再从箱娃左手边的访问者开始正式回合。

## 信息可见范围

公开：完整地图、访问者位置、各角落是否有盖放标志、保险箱初始固定位置、已公开手记、无声数字与行动顺序。

秘密：随机角落内容、亡骸指定位置、箱娃潜伏及方位栏、弱点、保险箱密码、初始候选和选择、后续能力手牌与牌库顺序、随身标志。普通潜伏只告知被替换的一枚，不因服务器保存全盘而提前查看其他棋子；访问者可自行全局公开其本次发现或随身标志。

本项目的12种道具候选已由用户明确确认；不再把该处候选池与已经确定的22片混合池、亡骸设置及初始能力列为缺失资料。
