# 箱娃 · 四／五人联机版

**当前规则：**[第三轮试玩修订](docs/试玩修订-2026-11-02-第三轮.md)优先于历史说明：开局随机发不同技能、死亡移出全部技能、绝望依牌序且最早第10次实际哭喊、对讲机固定配对、窥探角落仅本人可见。公开X、死亡位置、终局内容和可确认操作直接显示在地图，使用事件通过弹窗公示。

下载本仓库后，可以在自己的 Windows、macOS 或 Linux 电脑上独立运行，由电脑或手机浏览器加入。GitHub 仓库保存程序源码；实际游戏由启动程序的那台电脑提供。

每位部署者使用自己电脑上的服务、存档和独立生成的邀请码，程序没有连接原作者服务器的默认地址或备用入口。原作者电脑关机也不影响其他部署者运行；朋友需要使用本次部署者分享的网址和邀请码加入。

建房时可选择四人（一名箱娃、三名访问者）或五人（一名箱娃、四名访问者），默认四人。支持随机初始技能、九块地图拼接和秘密配置，以及无声模式下的移动、窥探、获取与补位、随身标志展示和赠送。已接入逃脱、讨伐、超度三条胜利路线，死亡后可作为箱人继续参与潜伏。旧房间和未记录人数的旧存档仍按四人恢复；房间人数在创建后固定，再开一局沿用原模式。

已接入主动道具、哭喊抽牌、两栏能力和打断；包含行李箱新增角落、手机私密查看、护符、灭火器、NO.7抢夺、NO.8与深菱神社之铃的连续翻牌。NO.12依卡面排除在无声模式外。详见[道具与能力结算](docs/道具与能力结算.md)，其中明确记录规则依据、用户选择和组合解释。

## 在自己的电脑上运行

1. 从 [GitHub 仓库](https://github.com/Steven060206/xiangwa) 下载 ZIP 并解压到固定文件夹，或用 Git 克隆。私有仓库需要先登录有访问权限的 GitHub 账户。
2. 安装 [Node.js 官方 LTS 版本](https://nodejs.org/zh-cn/download)，要求 Node.js 22 或更新版本。只运行游戏不需要执行 `npm install`。
3. 按下面的 Windows 双击方式或命令行方式启动。详细说明见[自行部署](docs/自行部署.md)。

### Windows：双击启动

1. 双击根目录的 **启动游戏.cmd**，保持游戏窗口开启。
2. 双击 **发放邀请码.cmd**，复制新生成的邀请码，默认有效30分钟、最多5个浏览器（含自己）。
3. 在这台电脑打开 [http://localhost:4173](http://localhost:4173)，验证邀请码后创建房间。同一局的朋友使用同一个邀请码验证，再加入房间。
4. 同一 Wi-Fi／局域网内的朋友打开游戏窗口显示的局域网地址。异地朋友使用 **远程联机.cmd** 显示的临时 HTTPS 网址；游戏窗口和远程联机窗口都要保持开启。

多人开局前，房主先使用与朋友相同的局域网或公网地址进入，再创建房间、复制邀请；不同地址保存的浏览器身份不会自动互通。

### Windows、macOS、Linux：命令行启动

在项目根目录打开终端：

```sh
npm start
```

保持窗口运行，另开终端在同一目录生成邀请码：

```sh
npm run invite
```

本机打开 [http://localhost:4173](http://localhost:4173)；局域网玩家打开启动时显示的局域网地址。异地联机另运行 `npm run share`；Windows 首次会自动下载官方隧道程序，macOS／Linux 先按[自行部署](docs/自行部署.md)安装 `cloudflared`。临时分享无需域名或 Cloudflare 账户。

开玩期间，主机要保持开机、联网和唤醒。结束时在远程联机窗口、游戏窗口分别按 `Ctrl+C`。下次使用同一数据目录启动即可恢复存档；临时分享网址变化会影响原浏览器身份恢复，详见[存档与地址](docs/自行部署.md#存档备份与地址)。

端口、监听地址和数据目录可通过把根目录 `.env.example` 复制为 `.env` 后修改；游戏、发码与临时分享命令会读取同一配置。默认端口4173，详情见[配置](docs/自行部署.md#配置)。

## 四／五人体验

1. 四名或五名玩家使用各自的电脑或手机浏览器。手机与服务所在电脑连接同一局域网，打开终端显示的局域网地址。
2. 一人填写昵称，选择“四人”或“五人”并创建房间，分享房间码或点击“复制邀请”。分享邀请前先用局域网地址打开页面，避免把只能在本机访问的 `localhost` 发给朋友。
3. 其余玩家填写昵称，用房间码或邀请链接加入。大厅按所选人数坐满，全员分别点击“准备”，此时不能提前抢选箱娃。
4. 全员准备后，房主点击“开始游戏”，全员一起进入“抢选箱娃”页面。先点击并由服务器成功受理的玩家扮演箱娃，其余三人或四人为访问者；系统从12种技能随机各发一张且不重复，公开“开局记录”，直接进入拼图，不需要再次准备。该记录不表示当前库存。刷新、断线和重启均不重新发牌。
5. 所有访问者轮流抽板、旋转、选择虚线位置并确认。抽到二楼大厅或地下室时单独摆放；二楼大厅摆好后，普通板可以接到二楼。同一地图板整体算一间房，内部分隔不需要另花行动移动。地图上的方格有固定编号，点击可查看名称，下方“角落位置对照”列出本楼层每个编号的完整位置；右侧操作使用同一编号，旋转后文字仍保持正向。
6. 九块全部摆好后，房主点击“开始开局配置”。箱娃秘密选择三个不同的密码数字和弱点，放置亡骸，在一块怨房板上选择初始潜伏角落。箱娃固定持有NO.11“虚假的哭喊”，另从NO.1—10随机抽三张不同能力并秘密三选一；候选及选择都只给箱娃，刷新或重启不会重抽。普通潜伏确认前不查看秘密棋子，确认后仅能回看被替换的一枚，记录随存档保留且不跟随取放更新。其他玩家在正门等待。
7. 访问者进入一楼大厅，按座次翻无声标志或持牌跳过。NO.8持有者以后回合需连续逐枚翻两枚，铃可在首次翻牌前选择额外一枚；逐枚累计，不超过10时完成要求后可声明行动，超过10立即停止并触发箱娃阶段，恰好10仍可行动。
8. 窥探结果默认仅本人可见；访问者可将本次发现或随身标志“全局公开”，不消耗标准行动，留下发现时的记录。可取的标志可以获取或盖回；取走后选空箱或随身标志补位。发现手记立即公开，并显示同编号能力说明；窥探保险箱后输入密码。页面的“展示、赠送与放置”可向同房朋友展示或赠送物品，赠送需对方接受。
9. 满足钥匙加出口、人偶加亡骸或有效武器命中箱娃的条件时，访问者获胜。窥探箱娃／箱人或用错误武器命中箱娃会死亡，死者转为箱人叠在凶手角落；全局公示该次死亡位置，后续潜伏仍保密。死亡移出全部技能，只继承随身标志；讨伐武器确认结算后一次性移出。
10. 箱娃阶段可以先哭喊，再选择设置一张能力或回收能力，然后点击“准备完毕，开始箱娃行动”。哭喊的宣告房间标在地图上，保留到下一次箱娃阶段开始；假哭同样只标宣告房间。已设置能力按时机和手记门槛发动；初始能力和绝望时刻获得的牌豁免手记门槛。NO.1—4默认只告知发动能力，箱娃可主动公开名称；NO.2必须先发动再选择路径，不查看途中棋子。NO.7可打断当前声明者抢取道具或随机标志，再将旧赃物交给本次被抢者；被抢者可重新声明。阶段能力完成后，箱娃与箱人依次完成普通潜伏，全部完成才重洗无声标志。总回合数按进入箱娃阶段的次数累计。
11. 主动访问者道具从“使用主动道具”选择，消耗标准行动，先声明后由箱娃确认。箱娃回答笔仙、占卜棒等问题；手机所见卡面只给使用者。行李箱只用一次，新增位置可正常探索与潜伏。铃额外翻牌完成后仍须选择“使用铃”，才会禁止下一箱娃阶段新设置B／C能力；已设置能力仍可发动或回收。
12. 数字超过10或“我在你身后”发动时，灭火器持有者须先选择使用／放弃；使用后跳过整次箱娃行动。“鬼来电”按用户选择：第一名访问者进入客厅后，全体解除最短移动限制。结局后锁定操作；全体存活访问者也可共同投降。
13. 游戏进行中，房主可点击顶部“结束本局”，确认后全员保留原房间、座位和身份返回大厅；房主变为箱人、正在等待其他人或撤销投票时也能结束。任意玩家可点击“退出房间”，确认后释放自己的座位，同时结束当前局，让其他人返回大厅；房主退出会转交房主，最后一名真人退出会清除房间和剩余人机。取消确认不会改变进度。
14. 关闭网页属于暂离。所有真人都离线后，保留5分钟重连时间；任意真人回来即取消倒计时，超过5分钟本局自动结束、原座位保留并返回大厅。SSE的多个标签页和轮询在线状态均计入。正常获胜后的复盘继续保留；停服、重启不视为玩家主动退出，已有存档不会在启动时批量清空。
15. 返回大厅会显示本局结束的原因。真人重新准备，人机自动准备；房主开始后重新抢选箱娃、领取道具和配置地图。正常结局仍可先查看完整复盘，再由房主点击“再开一局”。结束或重开会清空上一局进度、聊天与撤销记录，不会自动开始下一局；大厅可移除暂离座位、邀请替补或离席。

地图摆放与旋转向其他玩家实时预览；保险箱原址持续标记。全局公开发现只显示物品，不附发现角落；手记自动公开，无需再次点击。访问者随时可主动向同房访问者展示物品；死亡后技能全部移出，有随身标志时选择存活访问者继承。箱娃与箱人实时互见位置，并有阵营聊天；存活访问者有同房聊天，固定对讲机搭档另有私聊和双方确认的远程标志展示。消息仅发给发送时有权接收的玩家，换房或取得设备不追溯未收到的历史。

NO.5发动后在**下一次箱娃阶段开始前**按届时位置结算；“绝望时刻”洗牌后置底，**最早第10次实际哭喊**取得，来信可延后，次数不等于总回合数。旧存档从可确认次数接续。终局地图及“完整盘面复盘”向本局玩家展示全部角落、暂存物、库存与能力。细节见[第三轮试玩修订](docs/试玩修订-2026-11-02-第三轮.md)。

同一浏览器再次打开同一房间会恢复原座位，不会另占一席。关闭页面后也可恢复；同机模拟多人请每人使用独立浏览器配置或不同浏览器。大厅中房主可以点击暂离玩家旁的“移除”释放旧座位；有人离席或被移除后，其余玩家需要重新准备，开始游戏后不能移除玩家。

异地玩家应先从同一个公网地址进入，再复制房间邀请链接，避免分享只有房主电脑能访问的 `localhost`。临时分享、可选固定域名及常见连接问题见[自行部署](docs/自行部署.md)。

## 一个人与三／四个人机试玩

1. 创建时选择四人或五人模式，在大厅点击“补齐人机”，分别补入三名或四名人机并自动准备；房主可在开始前移除人机，为朋友留座。
2. 你点击“准备”，再点击“开始游戏”。抢选页中，点击“抢当箱娃”由你扮演箱娃，或点击“让人机当箱娃”让你作为访问者试玩。
3. 人机会完成自己的初始道具、抽板和摆放。轮到你的道具、地图或秘密配置时，它们会等待你的操作；地图完成后仍由房主点击“开始开局配置”。
4. 进入探索后，人机会执行自己的翻牌、移动、窥探、取放、必要回应和潜伏。你是箱娃时，需要确认访问者的声明；你是访问者时，人机箱娃会确认并回答你的道具询问。

人机使用基础策略和自己能看到的信息，没有其他座位的秘密视图；会随机探索，不代表熟练玩家的策略水平。你作为访问者投降时，人机访问者会跟随；人机不会自行发起投降。所有真人断线后暂停推进，重连后恢复。人机席位和对局随存档恢复；大厅最后一名真人点击离开时，人机也会退出并清理房间。

## 操作提示与撤销

- 顶部显示现在轮到谁、需要做什么；“前往操作”定位当前选择，“我的物品／我的能力”定位随身内容。探索时可直接查看角色、本人位置和总回合数。
- 获得物品、发现标志、死亡等重要事件会在最上层显示图案、名称和说明。点击卡片外、“返回游戏”或按 Esc 收起后，继续原来的选择。右上角“最近事件”可回看本页最近20条，刷新不会重播旧物品；私密通知只显示给本人。
- 初始领取、主动道具和夜视仪领取的选择处均可查看效果说明，已领取道具可点击“查看效果”。
- 地图圆标的数字对应玩家座位，位置条显示玩家名字和房间；点击名字可切换到所在楼层。箱娃和箱人的秘密位置只显示给本人。
- 电脑并排显示地图与操作，手机上下显示；地图和操作区各自滚动，无需反复把整页翻到下方。手机的角落位置对照默认折叠，可点击展开；“专看地图”可扩大地图，再点“返回操作”。手机横屏等高度不足的屏幕允许整页滚动，保证所有操作可到达。
- 顶部“撤销上一步”支持逐步回退最近40次成功操作，覆盖准备、配置、探索与结局。自己的未公开配置可直接撤回；共同进度需其他在线真人同意，人机自动同意。请求期间暂停操作，发起人或房主可取消。已看到的信息无法从人的记忆中删除。
- 撤销后人机先暂停，房主可点击“继续人机”；真人下一次成功操作也会继续人机。撤销记录随存档保留，旧存档从更新后的新操作开始记录。席位加入、离开或增删人机后清空记录，不能撤销座位变化。

具体行为见[撤销与试玩界面](docs/撤销与试玩界面.md)。

## 存档与重启恢复

`npm start` 默认把房间自动保存到项目目录的 `data/rooms.json`。创建、加入、离席及每次成功操作都会先完成保存，再通知玩家；保存失败时页面报错，本次操作不生效，可修复目录权限或磁盘空间后重试。

重启服务后，使用原地址打开即可继续原座位和进度；保持打开的页面会自动重连。地图、秘密开局、牌序、库存、待确认操作与结局都会保留。身份同时保存在标签页和浏览器本地，按房间恢复；关闭页面再打开原房间不会新增玩家，点击“离开房间”会清除该房间保存的身份。旧版本仍打开的页面刷新后会自动保存身份；旧版本已经关闭且凭证丢失的座位不能自动找回。清除浏览器数据、改用其他浏览器或换网址后，仍没有身份找回入口。

可在根目录 `.env` 中修改 `DATA_DIR`。未单独配置 `ACCESS_DIR` 时，邀请码记录跟随同一数据目录；相对路径均相对项目根目录。启动时终端会显示实际存档路径。

每个数据目录只供一个服务实例使用。备份或迁移前停止服务，复制整个数据目录；如果单独设置了 `ACCESS_DIR`，同时备份该目录。存档包含身份凭证和秘密盘面，`access.json` 包含邀请码管理密钥 `adminKey`，请保存在主机，不要提交到 Git 或分享给玩家。默认的 `data/` 已加入 Git 忽略，网页不能下载存档。存档损坏或格式不支持时服务会拒绝启动并保留原文件，需先修复或还原备份。

## 开发与验证

开发或运行浏览器测试时，先安装开发依赖；日常启动游戏无需此步骤。

```sh
npm ci
npm test
npm run test:browser
npm run verify:references
git diff --check
```

- `npm test`：地图、开局、无声模式、探索与胜负、主动道具、哭喊与能力、灭火器响应，以及真实 HTTP/SSE、轮询权限与隐藏信息集成测试。覆盖NO.7抢夺保密、NO.8与铃连续翻牌及存档恢复、人机过滤视图决策、固定种子完整对局、两种真人阵营的自动推进、离线暂停和存档失败重试；另有各阶段存档恢复、写入失败不生效、损坏存档拒绝启动、真实服务进程强制停止后的恢复，以及 Windows 公网分享脚本。
